# ОЧАКОВО: Путь Мастера
Цифровой HR-инструмент (мобильное приложение-игра) для привлечения студентов и выпускников на практику и стажировку в компанию «Очаково».

##  О проекте
Компания «Очаково» сталкивается с проблемой старения кадров и низкой конверсией в найм среди молодежи. Традиционные HR-инструменты скучны, а бренд воспринимается молодежью только как «полка в супермаркете».
Наше решение — это визуальная новелла с мини-играми, которая в легкой игровой форме знакомит игрока с историей завода, его ценностями и реальными вакансиями. В конце игры пользователь проходит тест-резюме, которое отправляется в HR-отдел.

## Ключевые механики
1. Визуальная новелла: Игрок общается с персонажами-маскотами (Квасенок, Ай-Ай, Акула Барон, Китоглав Кирилл, Крокодил Зубастик).
2. Мини-игры:
    * Выбор напитка (Квасенок).
    * Нажатия на склянки (Лаборатория Ай-Ая).
    * Мемори с профессиями (Цех розлива Китоглава).
    * Раннер (Технологический цех Акулы).
    * Ловля коробок (Склад Крокодила).
3. Прогресс-бар (Тамагочи): Квасенок «растет» вместе с игроком. Бегунок выполнен в виде логотипа «Очаково».
4. Сбор данных (Резюме): В финале игрок заполняет резюме (ФИО, телефон, город, выбранный отдел, вакансия) и может прикрепить PDF-файл.

## Технический стек
*   Язык: Java
*   Среда разработки: Android Studio
*   База данных: Room (SQLite) — для локального хранения пользователей, прогресса и данных резюме.
*   UI: XML-разметка, Material Design (фирменные цвета брендбука «Очаково»: красный `#D50032`, зеленый `#84BD00`).
*   Анимации: Встроенные анимации Android (Property Animation, Handler).

##  Как запустить проект
1.  Скачайте и установите Android Studio (последнюю версию).
2.  Склонируйте репозиторий или скачайте ZIP-архив с проектом.
3.  Откройте Android Studio и выберите File → Open, указав папку с проектом (там, где лежит файл `settings.gradle` или `build.gradle`).
4.  Дождитесь завершения синхронизации Gradle (внизу экрана будет полоса загрузки).
5.  Создайте виртуальное устройство (эмулятор) или подключите реальный телефон по USB с включенной отладкой.
6.  Нажмите зеленую кнопку Run ▶ (или Shift + F10) в верхней панели.

##  Как установить на реальный телефон (APK)
1.  Перейдите на сайт приложения.
2.  Нажмите на кнопку скачать приложение и дождитесь конца загрузки.
3.  Установите приложение на телефон (разрешите установку из неизвестных источников, если попросит).
Важно: После установки, если приложение вылетает при запуске, зайдите в настройки телефона → Приложения → Очаково → **Очистить данные** (это нужно из-за обновления структуры базы данных Room).

##  Структура проекта (ключевые файлы)
*   `LoginActivity.java` / `RegisterActivity.java` — Вход и регистрация (сбор ФИО и телефона).
*   `SessionManager.java` — Управление сессией пользователя и показом пролога.
*   `TamagotchiActivity.java` — Главный экран (Хаб) с выбором уровней.
*   `DialogActivity.java` — Универсальный экран для визуальной новеллы (с эффектом «печатной машинки» и выбором ответов).
*   `QuestionActivity.java` — Диалог-опрос перед финальным резюме.
*   `ResumeActivity.java` — Экран проверки резюме и прикрепления PDF.
*   `Level1BottleActivity.java` — Игра с бутылками (Квасенок).
*   `Level2BottleActivity.java` — Игра с колбами (Ай-Ай).
*   `Level3RunnerActivity.java` — Раннер (Акула Барон).
*   `Level4MemoryActivity.java` — Мемори (Китоглав Кирилл).
*   `Level5CrocodileActivity.java` — Ловля коробок (Крокодил Зубастик).
*   `User.java`, `UserDao.java`, `AppDatabase.java` — Настройка локальной базы данных Room.
